# ✊✌️🖐️ QRじゃんけんバトル

QRコードを使って二人で楽しく遊べる本格じゃんけんWebゲームです！  
スマートフォンやPCのブラウザで、インストール不要・完全無料で今すぐ遊べます。

---

## 🚀 すぐに遊ぶ方法

1. フォルダ内の **`start.bat`** または **`index.html`** をダブルクリックしてブラウザで開きます。
2. 画面のメニューから好きな遊び方を選んでスタート！

---

## 🎮 3つのあそび方モード

### 1. 📱 部屋をつくる / QRコードでリアルタイム対戦（おすすめ！）
**【スマホとPC、またはスマホ2台で対戦】**
- 1人目が **「部屋をつくる (ホスト)」** を押すと、画面に大きな招待用QRコードが表示されます。
- 2人目がスマホの標準カメラ（またはアプリ内の「QRコードをスキャンして参加」）でQRコードを読み取ります。
- 2人の画面が自動的につながり、**リアルタイム対戦**がスタート！
- **「最初はグー！じゃんけん…」** の掛け声とともに、✊グー・✌️チョキ・🖐️パーを選択。
- 相手が手を選ぶと「相手が手を選びました…！」と表示され、両者が選んだ瞬間に**「ぽん！」**で一斉オープン！
- 勝敗演出・効果音・紙吹雪・連勝記録・リアクションスタンプ（👏🔥🎉😭😱）機能付き！

### 2. 📷 カメラにかざして対戦（1台の端末で遊ぶ）
**【1台のPCやスマホのWebカメラの前に2人で座って勝負】**
- プレイヤー1が「グー・チョキ・パー」のQRコードをカメラにかざす（ピピッ！「P1準備完了」）。
- 次にプレイヤー2が自分の手札QRコードをカメラにかざす（ピピッ！「P2準備完了」）。
- 両者の手をカメラが読み取った瞬間に、画面で**「ジャン！ケン！ポン！」**とオープンして勝敗判定！
- メニューの「じゃんけんQRカード一覧」を別スマホで見せたり、印刷してカードとして使えます。

### 3. 🔒 オフライン秘密QR対決（完全通信なし）
**【電波のない場所でもスマホ同士のカメラだけで勝負】**
- プレイヤー1がスマホで手を選び、暗号化された秘密QRコードを生成。
- プレイヤー2がカメラでそのQRコードを読み取ってから自分の手を選ぶと、勝敗がオープン！

---

## 🛠️ 主な機能・特徴

- **リアルタイムP2P通信**: WebRTC (PeerJS) により、サーバーのセットアップ不要で端末同士が直接接続。
- **後出し防止システム**: 相手が選択した事実のみを先に伝え、両者が選び終えた後でのみ手を相互開示。
- **リッチなサウンド＆演出**: Web Audio API シンセサイザーによる効果音（クリック音、カウントダウン、ファンファーレ、あいこ音など）と、Canvasによる紙吹雪アニメーション。
- **自立型QRコードエンジン**: 外部サービスに依存せず、ブラウザ内で高速にQRコード生成＆カメラ認識（BarcodeDetector / jsQR）。
- **完全レスポンシブ対応**: スマートフォン（縦向き・横向き）およびPCの大画面に最適化。

## ❓ よくある質問・トラブルシューティング

- **Q. カメラが起動しません**
  - ブラウザのカメラアクセス許可が「許可」になっているかご確認ください。
  - カメラが使えない環境でも、「手動でルームIDを入力」すれば問題なく対戦可能です。

- **Q. ローカルファイル(file://)のままスマホで読み取れますか？**
  - PC上の `file://` のURLは、そのままではスマホのブラウザから開けません。
  - スマホと対戦したい場合は、以下のいずれかで簡単に遊べます：
    1. スマホ側でも `index.html` を開いてスマホをホストにする
    2. GitHub Pages や Netlify / Vercel などに本フォルダをアップロードして開く
    3. 「カメラにかざして対戦」モードなら、設定不要で画面のQRをかざすだけで遊べます！
